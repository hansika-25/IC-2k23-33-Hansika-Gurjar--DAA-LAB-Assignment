## About the Repository

This repository contains the programs, implementations, flowcharts, and experimental analysis completed as part of the Design and Analysis of Algorithms (DAA) Lab.

The repository covers fundamental algorithmic techniques including searching, sorting, divide-and-conquer, greedy method, dynamic programming, backtracking, traversal and search, and NP-Hard/NP-Complete problems.
